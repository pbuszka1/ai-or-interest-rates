# Documentation

Start with the [paper](../paper/ai_or_interest_rates.pdf), its [technical version](../paper/ai_or_interest_rates_technical.pdf), or the [README](../README.md). These files
hold the supporting detail.

| File | What it answers |
|---|---|
| [SCORECARD.md](SCORECARD.md) | What every analysis found, on one page (generated from `results/`) |
| [PREREGISTRATION.md](PREREGISTRATION.md) | What was fixed before Round 2 ran: tests, checks and decision rules. Hash-locked, so never edited |
| [METHODOLOGY.md](METHODOLOGY.md) | The original research plan, written before any results |
| [PREREGISTRATION_STATUS.md](PREREGISTRATION_STATUS.md) | Each pre-registered item, checked against the code: done, changed or not run |
| [DATA_VALIDATION.md](DATA_VALIDATION.md) | How the data compares with published BLS and Census figures |
| [VERIFICATION_AUDIT.md](VERIFICATION_AUDIT.md) | Estimators checked against reference packages, the data pipeline checked column by column, and every paper number checked against the saved results |
| [PUBLIC_RELEASE_AUDIT.md](PUBLIC_RELEASE_AUDIT.md) | The pre-release check of secrets, data licensing, links, checksums, stale numbers, notebooks and setup |
| [DATA_MANIFEST.csv](DATA_MANIFEST.csv) | A SHA-256 checksum, size and date for every raw and processed data file, to tell whether a rerun used the same data |
| [LIMITATIONS.md](LIMITATIONS.md) | The full list of limitations; the paper gives a short version |
| [DECISIONS.md](DECISIONS.md) | Each choice that shaped the results, why, and the alternative not taken |
| [IPUMS_EXTRACT.md](IPUMS_EXTRACT.md) | How to reproduce the CPS extract, which can't be redistributed |
